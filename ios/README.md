# Hymn Finder для iOS

Нативное SwiftUI-приложение с офлайн-каталогом. Минимальная версия iOS — 17.

## Открыть и запустить

1. Откройте `HymnFinder/HymnFinder.xcodeproj` в Xcode.
2. Выберите симулятор iPhone и нажмите ▶︎.
3. Для запуска на личном iPhone откройте target **HymnFinder → Signing & Capabilities**, выберите свой Team и при необходимости замените Bundle Identifier.

## Обновить каталог из данных бота

Из корня репозитория выполните:

```bash
python3 scripts/build_ios_catalog.py
```

Затем увеличьте build number (`CURRENT_PROJECT_VERSION`) перед новой загрузкой в App Store Connect.

## Что входит в MVP

- поиск по номеру, названию и тексту;
- фильтр по сборнику;
- четыре языка и работа без интернета;
- избранное на устройстве;
- изменение размера текста, копирование и системная отправка.

До публичного релиза нужно документально подтвердить право распространять тексты каждого сборника, подготовить страницу поддержки и политику конфиденциальности.
