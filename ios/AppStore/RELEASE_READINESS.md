## Техническая проверка перед архивом

- [ ] Сборка Release без предупреждений и ошибок.
- [ ] Корректные название, Bundle ID, версия и номер сборки.
- [ ] Иконка App Store без прозрачности и корректный набор размеров.
- [ ] Тест на реальном поддерживаемом iPhone.
- [ ] Тест на самой ранней поддерживаемой версии iOS.
- [ ] Поиск по номеру, названию и тексту открывает нужный гимн.
- [ ] Работают избранное, быстрый доступ и изменение размера текста.
- [ ] Язык определяется по системе и меняется вручную.
- [ ] Смена языка не переводит и не повреждает тексты песен.
- [ ] Приложение работает без интернета.
- [ ] Нет битых ссылок, пустых экранов и обрезанного текста при крупном системном шрифте.
- [ ] Проверены светлая и тёмная темы, если обе заявлены.

## Материалы App Store Connect

- [ ] Название, подзаголовок, описание и ключевые слова для каждой локализации.
- [ ] Скриншоты на требуемых Apple размерах без рамок симулятора и отладочных элементов.
- [ ] Support URL и Privacy Policy URL.
- [ ] Категории приложения.
- [ ] Возрастная анкета.
- [ ] App Privacy.
- [ ] Контакт App Review с действующим телефоном и email.
- [ ] Review Notes с примером поиска (`111`) и пояснением, что вход не требуется.
- [ ] Export Compliance: проверить фактическое использование шифрования при создании сборки.
- [ ] Content Rights: подтвердить право на сторонний контент.
- [ ] Декларация trader/non-trader для стран, где она требуется.

## После выхода

- [ ] Еженедельно проверять обращения поддержки и отзывы.
- [ ] Обновлять приложение при новых версиях iOS и требованиях Apple.
- [ ] Перед каждым релизом повторно проверять App Privacy и права на новые данные.
- [ ] Хранить журнал версий, известных проблем и исправлений.
- [ ] Следить за сроком членства Apple Developer Program и актуальностью договоров.
