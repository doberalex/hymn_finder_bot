# Hymn Finder Bot

Telegram-бот для поиска христианских гимнов и песен по нескольким языкам и песенникам.

## iOS-приложение

Нативное офлайн-приложение развивается отдельно в ветке `doberalex/ios-app`, но использует те же исходные песенники из `import/`. Xcode-проект находится в `ios/HymnFinder/`, а компактный каталог для приложения создаётся командой:

`python3 scripts/build_ios_catalog.py`

Инструкции по запуску и App Store находятся в `ios/README.md` и `ios/APP_STORE_GUIDE_RU.md`. Серверный код Telegram-бота и способ его SFTP-деплоя не изменяются.

## Ветки разработки

Все ветки, создаваемые от `main`, именуются с префиксом `doberalex/`, например `doberalex/ios-app`.

## Локальный запуск

1. Создайте виртуальное окружение:
   `python3 -m venv venv`
2. Установите зависимости:
   `venv/bin/pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env` и заполните персональные значения.
4. Запустите:
   `venv/bin/python run.py`

Файл `.env` содержит секреты и исключён из Git.

## Импорт песен

Исходные данные находятся в `import/`. Для импорта используется:

`venv/bin/python import_songs.py`

Перед импортом обязательно проверьте настройки базы данных в `.env`.
